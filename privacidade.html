Política de Privacidade — CMO-AI

Última atualização: 23 de novembro de 2026

1. Sobre o app

O CMO-AI é uma ferramenta interna da 4P Capital, usada exclusivamente pela equipe de marketing para automatizar tarefas com Google Drive, Docs e Planilhas. Não é oferecido ao público.

2. Dados acessados

Com autorização explícita do usuário via Google OAuth, o app acessa arquivos do Google Drive, Docs e Planilhas (e, quando autorizado, Gmail e Agenda) das contas conectadas.

3. Uso dos dados

Os dados são usados apenas para executar as tarefas solicitadas pelo próprio usuário. Não são vendidos, compartilhados com terceiros nem usados para publicidade.

4. Armazenamento

Os tokens de acesso ficam armazenados localmente no computador do usuário. O app não mantém servidores próprios com dados das contas.

5. Uso limitado

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
